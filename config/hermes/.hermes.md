## Vikunja (taakbeheer)
Self-hosted op `__BOOTSTRAP_VIKUNJA_HOST__`.
De Vikunja API gebruikt non-standaard HTTP-methoden — curl en directe API-calls werken niet.
Bij elk Vikunja-verzoek: gebruik de terminal tool en voer het script direct uit. Nooit antwoorden vanuit geheugen of context — altijd live via het script. Nooit beschrijven wat je gaat doen.

```
bash ~/.hermes/scripts/vikunja.sh projects
bash ~/.hermes/scripts/vikunja.sh tasks <project_id>
bash ~/.hermes/scripts/vikunja.sh create <project_id> <titel> [beschrijving] [due YYYY-MM-DD]
bash ~/.hermes/scripts/vikunja.sh done <task_id>
bash ~/.hermes/scripts/vikunja.sh delete <task_id>
```
